# Security and publication safety

This collection supplies instructions and optional local utilities. It does not grant an agent additional permissions, install dependencies automatically or configure remote services.

Inspect downloaded code before running it. Keep credentials in your host's supported secure storage, not in skills or examples. Consider the data-sharing policies of your AI provider before attaching private documents.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ak-debug/ai-workbench/security/advisories/new). Do not post credentials, confidential data or exploit details in a public issue. This is a personal open-source project maintained on a best-effort basis; there is no response-time guarantee.

Before the first push, inspect all files and verify publication rights. The included validator detects selected credential patterns, local personal paths and common non-public domains; it cannot determine whether arbitrary prose or images are confidential.
